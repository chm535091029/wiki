四大核心机制详解

CC Plan Mode 封闭状态机
三段式闭环：
EnterPlanMode → [写 plan] → ExitPlanMode → [实现] → VerifyPlanExecution
  • prePlanMode 存档：保存旧 mode，退出时恢复
  • 计划持久化：ExitPlanMode 写 plan 到 ~/.claude/plans/id.md
  • Plan Mode 守卫：写工具直接不可见
模型永远绕不开 plan → verify 闭环
CC 动态 Skill 发现
系统根据行为推断：
文件操作(Read/Write/Edit)
→ discoverSkillDirsForPaths
→ 遍历父目录找 .claude/skills/
→ addSkillDirectories + clearCommandsCache
不靠手动注册，懒加载
CC File Read 去重与豁免
双层防御：
Layer 1: fileStateCache LRU 100/25MB
→ 命中返回 "Already read"

Layer 2: Read 豁免
maxResultSizeChars=Infinity
→ 不进入 50K 预算层
防止"压缩→读→再压缩→再读"死循环
