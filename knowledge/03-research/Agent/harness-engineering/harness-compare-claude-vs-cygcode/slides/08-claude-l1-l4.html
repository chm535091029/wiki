L3 Permission 模式（6 种 + 切换）

每个 tool_use 前必走 5 级判定栈

[1] Hook permission (allow/deny/ask) [2] Tool.requiresUserInteraction()? [3] settings.json rule match (allow/deny/ask) [4] Mode default (见下方 6 种 mode) [5] Classifier (auto mode 才走) — deny > hook allow — 防御纵深

6 种 Mode 与切换

default → 每个非读工具需用户确认（通用默认） plan → 禁止写操作，只能跑只读工具 → EnterPlanMode 工具调用 → 切换到 plan → prePlanMode 保存旧 mode → 退出时恢复 acceptEdits → 自动批准 Edit/Write，其他需确认 → settings.json 或 /acceptEdits 命令切换 bypassPermissions→ 全自动（CI/脚本场景） → --bypass-permissions 启动参数 dontAsk → 拒绝非白名单操作（严格环境） → settings.json deny 规则 + dontAsk mode auto → transcript classifier 决定 → AI 自动分析对话决定 allow/ask/deny

会话级持久：mode 存 appState.toolPermissionContext.mode，每轮 query 传给 toolUseContext

plan mode 封闭状态机：EnterPlanMode → 写 plan → ExitPlanMode(保存到文件) → VerifyPlanExecution
