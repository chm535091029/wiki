Shared Philosophy · 三条基本原则

两套体系完全一致的核心心法

① 规则不依赖模型记忆

所有长期有效的约束，每轮都重新「推」到模型面前。不指望模型在前几轮看到后就记住。

CygCode: 每轮重建 CC: per-turn 再注入
② 软 + 硬约束分层

System Prompt 中的规则是软约束（模型可能违反），Tool 协议和 Permission 是硬约束（模型必须按 schema 写才能调通）。

CygCode: XML schema CC: canUseTool
③ 所有状态外化

任务进度、文件状态、环境信息，全部由系统侧维护并在每轮显式注入。模型不需要「自己记住」。

CygCode: FocusChain CC: AppState
✓ 两套体系在「不依赖模型记忆」「软硬约束分层」「状态外化」三个核心原则上完全一致。
差异在于工程实现分层方式和细节覆盖度。
