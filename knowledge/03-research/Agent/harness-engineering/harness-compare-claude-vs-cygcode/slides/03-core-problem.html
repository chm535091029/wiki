LLM 为什么会在多轮对话中「跑偏」

两套 Harness 体系的出发点完全一致——识别到 LLM 在多轮 Agent 场景中的四个结构性弱点

↘︎

上下文衰减

早期指令权重相对降低，模型倾向关注最近的内容（recency bias）

↗︎

指令漂移

模型在长任务中倾向于「自己找合理路径」，覆盖或忘掉用户的特殊约束

◻︎

状态丢失

模型是「无状态」的，每轮只能看到 messages；没有「我刚才做到第几步了」的内部记忆

✓

目标偏移

完成若干子目标后，模型容易「宣告完成」而不再检查后续任务

共同结论： 不能依赖 LLM 自身记忆或自控力。规则必须外化为系统侧强制注入、强制校验、强制纠正的可观测、可调整机制。
