CC Todo/Task 系统详解：五层提示协同 + V1/V2 双系统

提示词与 Task/Todo 的五层协同体系

1 系统提示词 (编译时) "Break down and manage your work with the TaskCreate tool"
2 工具 Schema (运行时) TaskCreate/Update/List/Get 各自 prompt() 返回详细使用说明
3 每轮自动提醒 (按10轮) getTaskReminderAttachments() → isMeta 注入: "task tools haven't been used"
4 工具返回值引导 TaskUpdate 完成时: "Call TaskList to find your next available task"
5 工具可见性控制 V1/V2 互斥 · 异步 agent 仅 TodoWrite · Teammate 全部 Task 可用

L1 系统提示词

getUsingYourToolsSection() 中动态选择: find([TASK_CREATE_TOOL_NAME, TODO_WRITE_TOOL_NAME]) → "Break down and manage your work with the {TaskCreate} tool" "Mark each task as completed as soon as you are done." "Do not batch up multiple tasks before marking completed."

其他工具（TaskUpdate/List/Get）不出现在顶层提示词，而是通过各自的 prompt() 注入 tool schema

L2 每个工具的 Prompt

TaskCreate:

  • 适用：3+ 步骤/Plan mode/多任务/新指令后立即创建
  • 不适用：单一简单任务、琐碎无收益
  • 提示：创建后用 TaskUpdate 设依赖、先 TaskList 查重

TaskUpdate:

  • 可更新字段：status/subject/description/activeForm/owner/addBlocks/addBlockedBy
  • 提示：更新前先 TaskGet 获取最新状态

TaskList:

  • 使用场景：找活干（pending+无owner+未阻塞）、检查进度、查找阻塞
  • Teammate 模式：完成后 TaskList → 认领 pending 任务 → TaskUpdate 设 owner

V1 · TodoWrite (deferred · AppState 内存)

TodoItem { content, status:"pending/in_progress/completed", activeForm } → TodoWrite({todos: [...]}) → shouldDefer=true → 非阻塞 → 全部 completed → 自动清空 → 3+项无验证 → nudge

V2 · Task 四工具 (均 shouldDefer · 文件持久化)

~/.cline/tasks/{taskListId}/ ├── 1.json / 2.json / .lock / .highwatermark TaskCreate → 自增ID + 写文件 + notifyUi TaskGet → JSON读取 + Zod校验 TaskList → 并行读JSON + 过滤已完成blocker TaskUpdate→ 6种操作(状态/完成/删除/修改/依赖/分配)

完整生命周期示例：五层协同如何引导模型

用户: "帮我实现博客系统，需要注册、文章发布、评论功能" // L1 系统提示词: "Break down and manage your work with TaskCreate" // L2 TaskCreate 描述: "创建任务，用于跟踪进度" → TaskCreate("实现用户注册") → TaskCreate("实现文章发布") → TaskCreate("实现评论功能") // 5轮后没用过TaskUpdate → L3 自动提醒注入 → 自动提醒: "The task tools haven't been used recently..." // 完成注册后 → L4 工具返回值引导 → TaskUpdate({ id:1, status:"completed" }) ← "Task completed. Call TaskList to find your next task..." → TaskList() → TaskUpdate({ id:2, status:"in_progress" }) // 中途插入 + 删除（增量修改 + 硬unlink） → 用户: "加分类管理" → TaskCreate("实现文章分类管理") → 用户: "评论不需要" → TaskUpdate({ id:3, status:"deleted" }) ← 磁盘3.json被unlink + 依赖引用被清除 // L5 工具可见性: teammate可看到全部任务，异步agent只能V1

提醒机制

TODO_REMINDER_CONFIG = { TURNS_SINCE_WRITE: 10, TURNS_BETWEEN_REMINDERS: 10, } → isMeta元消息: "task tools haven't been used..." + 当前任务列表 → 冷却10轮，不进REPL UI
